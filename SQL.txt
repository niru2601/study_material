4) UNIQUE, CLUSTER AND NON CLUSTER INDEX - 
	UNIQUE INDEX - PRIMARY KEY OF A TABLE IS UNIQUE INDEX
	
	CLUSTER INDEX - TO CREATE CLUSTER INDEX, YOU NEED TO REMOVE PRIMARY KEY FIRST.
	When a clustered index is created on a column, SQL Server reorders the data in the table based on that index.
	TABLE CAN HAVE ONLY ONE CLUSTER INDEX.
	
	NON CLUSTER INDEX - it will not sort or change the physcial structure of data.
	table can have more than 2 non cluster index.

7) Normalization - to remove duplicate records and redundancy 
	1NF - all records with unique value
	2NF - 1NF and should have single column primary key 
	3NF - 2NF AND must not have any transition functional dependancy 
	BCNF - if many candidate key present and then make sure that only one candidate key present per table.

	drop - can not roll back
	truncate - can not roll back
	delete - can be roll back before commiting 
	
9) ACID - atomicity - either successfull or fail. if any transaction fails then all transactions will fail and it will not reflect on database.
	consistancy - ensure that data must be have all validation rules.
	isolation - it is nothing but concurrency control.
